# Floristwork

A work orders app for independent floral designers.

Site: https://floristwork.com
Demo: https://demo.floristwork.com (fictional shop, made-up data)

## The problem

Independent floral designers don't have a digital record of their order history that they can analyze or audit, so they start from zero on every order.

## What it does

- Takes phone orders quickly.
- Moves each order across a status board.
- Prints build and delivery tickets.
- Keeps client records.
- Shows what the month made.
